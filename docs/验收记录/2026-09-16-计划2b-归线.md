## 发现的问题

### 1. L-003：跨度大的支线被按「因果直觉」重排，τ 只有 0.32

这条线 18 块，横跨第 15–49 回。模型排成：21 → 38 → 38 → 38 → 38 → 39 → 39 → 40 → 40 → **15** → 37 → 41 → **16** → **16** → **15** → 41 → 45 → 49（加粗的是错位的 4 块）。

错法很整齐：模型把「刘电访岑公子家扑空、路上遇兄长刘云、搬柩」（第 21、38–41 回）当成这条线的开头（给的时间 t=0～0.25），把「刘电送玉霜娘到蒋府、试鐵胎弓、蒋公提亲、与苏小姐结姻、慈云庵访禅师」（第 15、16 回）当成后续（t=0.5～2.6）。原书里恰恰相反：先到蒋府结姻，后来才有搬柩寻访。

看得出是按线名「搬柩结姻」的字面因果顺序推的——先搬柩再结姻，而不是按文本里的时间线索。这条线模型给的 `conf` 大多是「中 / 低」，说明它自己也没找到硬锚点。

影响：单线 τ 0.32，但加权后整本仍 0.93（主线 52 块几乎全对）。**已记进已知问题**：跨度大、时间锚点弱的支线，排序可能按主题因果而不是文本顺序，作者在界面上要能看到 `conf` 低的段落。

### 2. 冷门书上，缺口抓的是对话里的回指，不是「被删的整回」

《西游记》被删的 5 回**全部**被标成缺口，位置也给了：

| 删掉的回 | 对应缺口 |
|---|---|
| 第 8 回 | Q-001 观音领佛旨上东土寻取经人、Q-004 如来赐观音三个箍儿 |
| 第 21 回 | Q-005 灵吉菩萨降黄风怪 |
| 第 43 回 | Q-006 前遇黑河身有难 |
| 第 52 回 | Q-007 如来暗示罗汉说出妖的根原、Q-008 行者请天兵被白森森的圈子套去 |
| 第 85 回 | Q-012 小钻风被孙行者打杀 |

《雪月梅传》91 条缺口里，**没有一条对得上被删的 5 回**（第 5 回雪姐渡江遇骗、第 11 回刘电殷勇结义、第 22 回还魂后运柩回吉水、第 27 回拜严先生租王进士房、第 43 回夫人斩倭寇）。91 条几乎全是对话里一句带过的往事（「前月接到金舅来信」「老母年高，已三科不曾会试」），而且 **87 条的 `after` 和 `before` 两头都是 null**（只有 4 条给了一头），等于没定位；另有 3 条 `thread` 是 null。对照《西游记》那本：42 条缺口**每一条**都至少给了一头的位置，`thread` 没有空的。

差别的来源：《西游记》删掉的回，后文会反复复述（取经路上常提前情），模型顺着复述就能认出缺口；《雪月梅传》删掉的回后文很少回顾，模型只能抓住零碎的回指。

这不是门槛项（设计里缺口只记录），但说明**缺口功能对「后文不复述」的稿子基本无效**，作者不能拿它当「查漏工具」用。已记进已知问题。

### 3. 费用：西游记 1.7 倍，雪月梅 1.08 倍

| | 估算 | 实际 | 倍数 |

| 西游记（只归线） | $0.2348 | $0.3996 | 1.70 |

偏差主要在归线这步：归线的输出 token 比估算模型假设的大（雪月梅归线输出 33.4 万 token，比输入 20.9 万还多——思考模式开 high，综合档一次要吐整条线的顺序和时间）。场景卡那步这次反而估准了（②a 改过提示词后，雪月梅 133 张卡只用了 205 次调用 = 每卡 1.54 次，低于②a 的 1.75）。

**②a 改的两句提示词（pov 没有明确视角人物就留空、quote 不许用省略号拼接）这次是第一次拿真模型验证：有效。**

### 4. 线内排序的预算保护这次没碰到

已知局限「线内排序不分段、没有预算保护，一条三千块左右的大主线会碰到输出上限」——这次最大的线是西游记 L-001 的 210 块，远低于会出事的量级，所以没暴露。真拿 200 万字的稿子跑时仍可能碰到。
