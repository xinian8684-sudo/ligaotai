## 深色模式

九页全过了一遍。朱红（缺口、严重矛盾、角标数字）在深色下够亮，世界色的段跟背景分得开，`--sunk` 的半透明底没有糊。

🔴 **抓到一个真 bug**：原生表单控件没接主题。深色下按钮是浏览器默认的浅灰底，字又继承了深色主题的浅色，**「保存」「测试连接」「跑」几乎看不见**；输入框全是白底，刺眼。修法：token 里声明 `color-scheme`，`base.css` 照原型 `.btn` 的样子给按钮和输入框兜底（`315d087`）。

## 没验到的（数据里没有这种情形，如实写）

- **失败的步骤**：两本书七步全是「已完成」。报错完整显示靠单元测试 + 这次改的 CSS，没在真画面上看过一行长报错。
- **排序失败的线**：两本书都没有 `order_failed` 的线，醒目提示只有单元测试守着。
- **pending / unassigned 非空**：雪月梅两区都是 0。
- **key 打码**：临时书库没配 key，看到的是「（没配）」。
- **换模型提示**：档案全是当前模型写的，提示条没出现过。
- **深色 1000px** 只过了全景一页。

## 留下的问题

1. **归线确认收起后，改名 / 设主线没入口了**。作者拍板的导航决定 1 是「实体 / 归线确认做成流水线子路由，没有待办时收起」。可归线页除了处理待办，还有**线改名、设为主线**这两个平时要用的操作——待办清零后导航收起，流水线第 6 行也只在有 pending 时给「去确认」，于是只能手敲网址进来。**当天作者定：归线页常驻导航**，已改（角标只在有待确认项时出现）。
2. **还有几处显示编号不显示名字**：归线页「世界」列显示 `W-01`，矛盾页出处显示 `L-004`。不影响使用，跟设定库那处是同一类，下次顺手改。
3. **场景编号没做跳转**：场景浏览 / 设定库 / 矛盾页里的 `S-0030` 还是纯文本（D4 故意没做，二期）。
4. **合并、拆分线只有接口没界面**；未分配的块是下拉选线再「归入」，不是拖拽（spec 写的是「拖进线」）。
5. 泳道图首尾单点区块的时刻还钉在 0 / 100，没挪到区块中点（跟现有断言冲突，偏差 ≤ 0.5%）。
