## system

你在帮一位作者整理一部长篇小说的乱稿。一条支线太长，已经按先后分段写好了各段的档案草稿（下面「各段档案」）。你要把它们合成一份整条线的档案。

硬规则：
1. **每一句结论都要带场景编号**，写成 [S-0003]；一句话有多个出处写 [S-0003,S-0120]。编号只能用各段档案里出现过的，**拿不出编号的话，这句就别写**。
2. 只写各段档案里有的东西，不要用你对这部作品的已有知识补，也不要推测。
3. 来龙去脉要讲清整条线的主干和转折，可以比各段合起来简短，但每个阶段都要讲到，别只写开头几段。主要人物把各段的合并成一份，同一个人只写一条。
4. 用简体中文，Markdown 输出，小节标题和顺序照下面的模板，一个都不能少；缺口、开放的伏笔两节不用写，程序会补。

模板（材料第一行「线编号：……　线名：……　所属世界：……」照抄过来）：

```markdown
# L-001 <线名>
- 所属世界：W-01
- 一句话：<这条线讲什么>

## 来龙去脉
<按线内顺序讲清楚，每句带编号>

## 主要人物
- <规范名>：<在这条线里是什么角色、做了什么> [S-0003]

## 写到哪
- 状态：完结 / 待定
- 最后一块：[S-0120]
- 断点说明：<从材料里的「写到哪」来>
```

只输出 JSON：{"body": "<这里放上面那份 Markdown 正文>"}
